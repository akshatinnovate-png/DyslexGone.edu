An accessibility OS for education.

Not a tutor with a chat box. A stack: a learner digital twin that tracks what a student knows, a curriculum graph that knows what has to come first, an engine that diagnoses which wrong rule produced a wrong answer, and a renderer that turns a concept into an animation, a lab, or a page that a dyslexic reader can actually get through.

Everything on this page is computed in your browser, right now. It is the production engine code, bundled for the web — no server, no API key, nothing pre-recorded. That is the design constraint: a hosted model is an upgrade, never a dependency.

Universal Accessibility Transformer

One passage in, eight readings out. It rewrites for a target grade, names the words it had to keep, scores every sentence for difficulty, builds a decoding guide for the hard ones, and produces an audio script with spelled-out mathematics. Paste in anything.

Misconception Engine

A grader says wrong. This says which wrong rule. It re-derives the student's answer from a catalogue of faulty procedures, and reports a match only when the faulty rule reproduces their answer exactly — so the diagnosis is evidence, not a guess.

Procedural Animation Engine

Each of these is generated as a timed scene graph and compiled to a self-contained animated SVG — no video files, no frames, nothing drawn by hand. The same compiler audits the scene for overlap, contrast and pacing, emits narration, and can re-render the whole thing motionless for anyone who needs that.

Virtual Lab Engine

Ten solvers, not ten canned demos: modified nodal analysis for DC circuits, RK4 for the pendulum, an exact-fraction integer nullspace for balancing chemical equations, Hardy–Weinberg for allele frequencies. Change a control and the physics is recomputed.

Curriculum Knowledge Graph

109 concepts and their prerequisite edges. Pick a target a student is failing and set how much they know: the tracer walks backwards to the root cause — the deepest unmet prerequisite — and returns the repair route in teaching order. This is what stops a student being re-taught fractions when the actual gap is division.

Explanation Quality Checker

Anything shown to a student passes this first. It checks for known falsehoods taught as fact, myths repeated without refutation, reading level above the learner, personal data, and prompt injection. It holds a veto: a blocking finding means the explanation does not ship.

What else is in the box

The browser only gets the parts that are pure computation. The rest needs the server, which runs on SQLite with no native dependencies — npm install && npm start, no configuration, no API key.

Run the whole stack

git clone https://github.com/akshatinnovate-png/dyslexgone.edu
cd dyslexgone.edu
npm install
npm run build
npm run doctor     # 11 self-checks, end to end, ~220ms
npm start          # http://localhost:8080/docs

Optional: set GROQ_API_KEY to let openai/gpt-oss-120b author animation storyboards and richer prose. Every feature works without it; the model is routed through a sanitizer that rejects malformed scenes and falls back to the deterministic engine.
